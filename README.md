# HackHarness

An authorization-first, multi-agent security research harness for reproducible testing of systems you own or are explicitly permitted to assess.

HackHarness is designed around specialist workers, model routing, durable claims, append-only evidence, deterministic verification, independent review, and benchmarking.

## Status

Initial implementation in progress.

## Safety model

HackHarness requires an explicit scope manifest. Network-capable work is denied unless the target matches the configured allowlist. The framework is intended for owned systems, local labs, CTFs, and explicitly authorized security research.
